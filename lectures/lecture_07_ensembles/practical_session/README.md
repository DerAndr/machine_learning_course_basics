# Ensembles Practical Session

This directory contains a 90-minute classroom practical for Lecture 07.

## Files

- `ensembles_practical_student_90min.ipynb`
- `ensembles_practical_student_90min.py`
- `README.md`

## Format

- The student notebook contains targeted TODO placeholders in the main model-building cells.
- The Python companion script mirrors the notebook structure for lighter review and diffing.
- The session is designed for two student groups:
  - Group A: classification
  - Group B: regression

## Teaching Intent

- Show why a single decision tree is often less stable than an ensemble.
- Contrast bagging via Random Forest with boosting libraries used in modern tabular ML.
- Give students a practical first orientation to XGBoost, LightGBM, and CatBoost.
- End with a short whole-class comparison of trade-offs, stability, metrics, and interpretability.
