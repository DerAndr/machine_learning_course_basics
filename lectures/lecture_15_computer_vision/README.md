# Lecture 15: Computer Vision

This directory currently contains a practical-first draft for an introductory Computer Vision block.

The material focuses on the visual intuition students need before and while using modern CV models:

- images as tensors;
- classical convolution filters;
- CNN layers, activations, and parameter counts;
- real object detection with YOLO;
- semantic segmentation;
- image embeddings and nearest-neighbor search;
- a bridge from image embeddings to multimodal image-text embeddings.

## Core Files

- `lecture_notes.md`
- `links.yaml`

## Practical Session

- `practical_session/`: 90-minute classroom practical covering classical filters, a small CNN on Fashion-MNIST, detection, segmentation, image embeddings, CLIP-style multimodal embeddings, and a short modern CV snapshot.
- `practical_session/computer_vision_practical_student_90min.ipynb`: student notebook with guided TODO cells.

## Draft Status

This lecture does not yet have a slide deck or separate lecture example notebooks in the repository.
The practical notebook is the canonical working artifact for now.
