## Lecture Examples

- `lecture_examples/example_01.ipynb` and `lecture_examples/example_01.py`: Exploratory Data Analysis - Demos [1-4]. EDA basics: summary statistics, distributions, and pairwise visual analysis.
- `lecture_examples/example_02.ipynb` and `lecture_examples/example_02.py`: Exploratory Data Analysis - Demos [5-6]. Automated EDA reports and interactive visualization tools for faster inspection.

## Practical Session

- `practical_session/eda_practical_student_90min.ipynb`: student practical with targeted TODO cells
- `practical_session/eda_practical_student_90min.py`: Python companion script for the practical notebook
- `practical_session/README.md`: practical overview, scope, and runtime notes

The practical covers:

- dataset structure, missingness, and type inspection on Palmer Penguins
- univariate summaries for categorical and numerical variables
- grouped comparisons across species, island, and sex
- correlation heatmaps, scatter plots, cross-tabs, and pair plots
- one optional automated-EDA example at the end
