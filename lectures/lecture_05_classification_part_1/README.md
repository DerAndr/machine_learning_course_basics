# Lecture 05: Classification Part 1

This directory contains the lecture materials for this topic.

## Core Files

- `lecture_notes.md`
- `links.yaml`
- `slides/lecture.pdf`
- `lecture_examples/README.md`
- `practical_session/README.md`

## Lecture Examples

- `lecture_examples/example_01.ipynb` and `lecture_examples/example_01.py`: K Nearest Neighbours Classifier. KNN classification mechanics and decision-boundary intuition.
- `lecture_examples/example_02.ipynb` and `lecture_examples/example_02.py`: Decision Tree Classifier. Decision-tree classification and split behavior.
- `lecture_examples/example_03.ipynb` and `lecture_examples/example_03.py`: Logistic Regression Classifier. Logistic regression for classification and probability-based decisions.

## Practical Session

- `practical_session/classification_part1_practical_student_90min.ipynb`: student practical with targeted TODO cells
- `practical_session/classification_part1_practical_student_90min.py`: Python companion script for the practical notebook
- `practical_session/README.md`: practical overview, scope, and setup notes

The practical covers:

- mixed-type preprocessing for tabular classification
- `KNN`, `DecisionTreeClassifier`, and `LogisticRegression` on Adult Census Income
- validation curves, learning curves, and optional Optuna-based tuning
- ROC, PR, calibration, confusion-matrix, and probability-distribution diagnostics
- threshold optimisation and model interpretation

The practical session is intentionally separate from `lecture_examples/`.
