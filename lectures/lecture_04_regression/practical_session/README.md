# Regression Practical Session

This directory contains a 90-minute classroom practical for Lecture 04.

## Files

- `regression_practical_student_90min.ipynb`
- `regression_practical_student_90min.py`
- `README.md`

## Format

- The student notebook contains targeted TODO placeholders and short answer cells instead of full solutions.
- The Python companion script mirrors the notebook structure for lighter review and diffing.
- The practical uses the **Auto MPG** dataset as a compact regression case study with missing values, mixed feature types, and clear model-comparison opportunities.
- The notebook is organized into four classroom blocks:
  - audit, visuals, and feature engineering
  - baseline linear regression workflow
  - regularization and tree-based models
  - residual diagnostics and wrap-up

## Teaching Intent

- Keep the strong visual intuition of the original regression lab while making the notebook easier to use as a classroom practical.
- Connect Lecture 04 topics directly to one end-to-end predictive workflow instead of treating OLS, VIF, regularization, and residuals as isolated ideas.
- Compare linear and tree-based regression on the same target so students can see the tradeoff between interpretability and flexibility.
- Reinforce that evaluation, multicollinearity checks, and residual analysis are part of regression work, not optional afterthoughts.
