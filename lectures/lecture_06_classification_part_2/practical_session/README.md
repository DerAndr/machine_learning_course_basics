# Classification Part 2 Practical Session

This directory contains a 90-minute classroom practical for Lecture 06.

## Files

- `classification_part2_practical_student_90min.ipynb`
- `classification_part2_practical_student_90min.py`
- `README.md`

## Format

- The student notebook contains targeted TODO placeholders instead of a full blank workflow.
- The Python companion script mirrors the notebook structure for lighter review and diffing.
- The session is designed for three student groups:
  - Group A: imbalanced binary classification
  - Group B: multiclass classification
  - Group C: multilabel classification

## Teaching Intent

- Keep the notebook runnable within a 90-minute session.
- Give each group a meaningful but limited coding load.
- End with a short whole-class comparison of metrics, trade-offs, and methodology.
